# Roblox assets

Record approved asset IDs here before importing more assets. No assets have been
imported for this template. Keep the import journal in `ASSET_IMPORT_RESULTS.json`.

Use a `## Pack folder name` heading (or its configured `assets.packs` title),
then a table with source names and IDs in backticks. Each row starts with the
source model name (without its extension), followed by its approved Model ID.
Record licensing, intended use and verification evidence alongside the table.
